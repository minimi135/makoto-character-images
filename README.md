# Makoto fairy world character images

Fairy-world image assets for Elyn. Files are copied byte-for-byte from the source project.

- Characters: 45
- Published images: 450
- Layout: `img/{character-code}/{existing-image-number}.png`
- Raw URL template: `https://raw.githubusercontent.com/minimi135/makoto-character-images/main/img/{CODE}/{NUMBER}.png`
- `characters.json` maps source FW codes to public two-letter codes.
- `images.json` lists every published file, expression label, and direct URL.

## Scene backgrounds

Five opening/location backgrounds are under `img/BG/{1..5}.png`. BG is reserved for backgrounds; its numbers are locations, not portrait expressions. `scenes.json` lists titles, file paths, raw URLs, and SHA-256 hashes.

- BG/1: 학교 — 전학 첫날
- BG/2: 로도노프 저택 — 저녁 식사 전
- BG/3: 일렌시아 성국 — 아침의 방문
